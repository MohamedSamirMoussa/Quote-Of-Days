# Quote of the Day

A lightweight browser app that displays a random quote on demand. It was built as a JavaScript practice project focused on DOM updates, events, and simple data handling.

## Features

- Generate a new quote with one click
- Random selection from a local collection of quotes
- Immediate DOM updates without reloading the page
- Responsive Bootstrap-based interface

## Built With

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript

## Run Locally

~~~bash
git clone https://github.com/MohamedSamirMoussa/Quote-Of-Days.git
cd Quote-Of-Days
~~~

Open index.html in a browser. No installation or build command is required.
